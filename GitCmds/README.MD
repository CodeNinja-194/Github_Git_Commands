# Git Commands Reference Guide

A comprehensive collection of Git commands and workflows organized by topic for quick reference and learning.

## Files Organization

### Basics & Setup

- **0.initialconfig.txt** - Setting up Git configuration (username, email, editor)
- **1.Status_initialising_tracking.txt** - Initializing repos, staging, committing, and tracking status
- **2.cloning_cloning_particularfile.txt** - Cloning repositories and specific files

### Undoing & Modifying Changes

- **3.gitignore_git_diff_skiping_staging_area.txt** - .gitignore, git diff, and skipping staging area
- **4.Moving_Renaming_stop_tracking.txt** - Moving, renaming files, and stopping tracking
- **5.git_reset_checkout.txt** - Resetting and checking out files
- **8.Unstaging_umodifying_restore.txt** - Unstaging and restoring files
- **15.git_revert_cherry_pick.txt** - Reverting commits and cherry-picking specific commits

### Remote Operations

- **7.git_remote_repository.txt** - Working with remote repositories, SSH, and pushing
- **11.publish_branch_remotely.txt** - Publishing branches remotely and deleting remote branches
- **16.git_fetch_pull.txt** - Understanding fetch vs pull operations

### Branching & Merging

- **10.Creating_and_Switching.txt** - Creating, switching, merging, and deleting branches
- **13.git_rebase.txt** - Rebasing commits onto other branches
- **17.git_conflict_resolution.txt** - Detailed conflict resolution strategies and tools

### Viewing History & Analysis

- **6.git_log+filter_commits.txt** - Git log commands and filtering commits by time/author
- **18.git_blame_reflog.txt** - Blame (who changed what) and reflog (recovery from mistakes)

### Stashing & Temporary Work

- **12.git_stash.txt** - Temporarily saving changes without committing

### Releases & Versions

- **14.git_tags.txt** - Creating and managing tags for releases

### Advanced Operations

- **19.squashing_commits.txt** - Combining multiple commits into one
- **20.common_mistakes_fixes.txt** - Common Git mistakes and how to recover from them
- **21.git_workflows_best_practices.txt** - Recommended workflows (Git Flow, GitHub Flow, Trunk-based) and best practices

### Configuration & Miscellaneous

- **9.alias_names.txt** - Creating Git command aliases for frequently used commands
- **22.additional_useful_commands.txt** - Utility commands (search, cleanup, statistics, debugging, bisect)
